I am an **Electrical Engineering undergraduate at the University of Moratuwa** interested in building intelligent systems that work beyond ideal laboratory conditions.

My work sits at the intersection of **AI, computer vision, robotics, sensing, control, embedded engineering, and autonomous systems**.

I particularly enjoy problems involving:

🧠 **Reliable AI** — understanding when models should and should not be trusted
👁️ **Computer Vision** — perception, detection, representation learning and VLMs
🤖 **Robotics** — connecting perception to physical actions
📡 **Sensors & Embedded Systems** — converting real-world signals into decisions
📊 **Experimental Engineering** — controlled testing, uncertainty and failure analysis

> ### 🎯 Current Mission
>
> Building intelligent systems that remain useful when **data becomes noisy, incomplete, shifted, ambiguous or unfamiliar**.

# 🧪 My Engineering Workflow

<div align="center">

```text
┌───────────┐
│  Problem  │
└─────┬─────┘
      ↓
┌────────────┐
│ Hypothesis │
└─────┬──────┘
      ↓
┌─────────────────────┐
│ Experimental Design │
└──────────┬──────────┘
           ↓
┌────────────────┐
│ Implementation │
└───────┬────────┘
        ↓
┌─────────────────────────┐
│ Quantitative Evaluation │
└────────────┬────────────┘
             ↓
┌──────────────────┐
│ Failure Analysis │
└─────────┬────────┘
          ↓
┌─────────────────┐
│ Reproducibility │
└─────────────────┘
```

**I don't only ask *“Does it work?”***

I also ask:

**“When does it fail?” • “Why does it fail?” • “Can we measure it?” • “Can someone reproduce it?”**
